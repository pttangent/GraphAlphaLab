The campaign identifier in the source directory is historical. GAL reads the governed GFF campaign contract and evaluates only contract sessions inside the explicit `2026-04-01` through `2026-07-22` range. The actual session count is written to the label manifests; no calendar-day count is assumed.

## One global DAG

Intraday and daily horizons are merged into one horizon manifest before Alpha begins. Therefore all of these tasks share one global ready queue:

```text
horizon × scope × factor
```

There is no scope barrier and no horizon barrier.

Intraday horizons:

```text
5m, 15m, 30m, 60m, 120m, 180m
```

Daily labels all enter at the next trading-session open:

```text
daily_n1_open_to_n1_close
daily_n1_open_to_n2_open
daily_n1_open_to_n2_close
```

The extended profile adds next-open entries held to N+3, N+5 and N+7 closes.

## Rolling design for a roughly 70-session sample

```text
5 sessions:  step 1, pulse diagnostic only
10 sessions: step 1, tactical monitor only
15 sessions: step 2, confirmation / promotion eligible
20 sessions: step 2, confirmation / promotion eligible
30 sessions: step 5, structural validation / promotion eligible
```

Windows of 40 and 60 sessions are deliberately excluded because they provide too few independent windows in this sample. Direction is predeclared when available; otherwise it uses only prior daily IC, with at least 15 and at most 30 training sessions.
