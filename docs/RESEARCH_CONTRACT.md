# Monthly alpha research contract

The baseline run is fixed before examining monthly outcomes.

1. Read governed NFF, P0 and P1 outputs without modifying them.
2. Discover every successful `date × layer × scale × variant` partition.
3. Build future direction and absolute-return risk targets only from data after each decision time.
4. Apply strict tradability filters only to evaluated target stocks; graph neighbors may come from the full eligible market.
5. Evaluate raw Node, one-hop Graph and strict leave-one-out P1 theme signals.
6. Residualize in decision-time cross sections in this order: traditional own-state controls → Node → Graph → P1.
7. Report snapshot, day and month stability, spread, coverage and governance failures.
8. Treat automatically discovered extensions as in-sample until a later month confirms them.
