# Operations checklist

- [ ] Install editable package with development dependencies.
- [ ] Run compilation, unit tests and CLI help.
- [ ] Run three-day smoke validation.
- [ ] Inspect governance findings.
- [ ] Interrupt once and verify `--resume` reuse.
- [ ] Confirm free disk remains above the configured gate.
- [ ] Run the full month.
- [ ] Review failures and monthly report.
- [ ] Validate candidates on a later out-of-sample month.
